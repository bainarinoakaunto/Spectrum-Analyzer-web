# 🎧 Spectrum Analyzer

ブラウザ上でマイクから音声を取得し、リアルタイムで周波数を解析・可視化するWeb版スペクトラムアナライザーです。

Pythonや専用サーバーを使用せず、ブラウザのWeb Audio APIを利用して音声解析を行います。

## 🛠️ 使用技術

| 技術 | 用途 |
|---|---|
| HTML5 | Webページの構造 |
| CSS3 | デザイン・レイアウト |
| JavaScript | 音声解析・データ処理・UI制御 |
| Web Audio API | マイク入力・音声解析 |

| FFT | 音声を周波数成分へ変換 |

## 📊 スペクトラムとは？

スペクトラムは、音声に含まれている周波数成分を表示したものです。

音には低い音から高い音まで、さまざまな周波数成分が含まれています。

```text
低い音                                      高い音
 │                                             │
 ▼                                             ▼
30Hz ───── 100Hz ───── 1kHz ───── 10kHz ───── 20kHz
```

Spectrum Analyzerでは、周波数ごとの強さをリアルタイムでグラフ表示します。

## ⚡ FFT

FFT（Fast Fourier Transform）は、音声などの信号を周波数成分へ変換するための処理です。

```text
時間領域の音声
〰️〰️〰️〰️〰️〰️〰️
       │
       │ FFT
       ▼
周波数領域
█  ██  █████  ██  █
30Hz ─────────── 20kHz
```

これにより、現在どの周波数の音が強いのかを確認できます。

## 🔒 プライバシー

音声解析はブラウザ上で行います。

このプロジェクトでは、マイクから取得した音声を外部サーバーへ送信して解析する仕組みを使用していません。

マイクへのアクセスについては、使用するブラウザの権限設定に従います。

## 🔐 HTTPSについて

マイクなどのブラウザ機能を利用する場合、ブラウザのセキュリティ制限に注意してください。

GitHub PagesではHTTPSで公開できるため、Web公開時の利用に適しています。

## ⚠️ 注意事項

* マイクへのアクセス許可が必要です。
* 使用するブラウザによって動作が異なる場合があります。
* マイクが接続されていない場合、解析できません。
* 音量や周波数の表示は、マイクや周囲の環境によって変化します。
* ブラウザのセキュリティ設定によってマイクが利用できない場合があります。
* マイクを使用するときは、ブラウザに表示される権限内容を確認してください。
